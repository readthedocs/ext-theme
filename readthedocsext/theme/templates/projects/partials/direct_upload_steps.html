{% load blocktrans trans from i18n %} {% comment %} Steps to upload documentation with direct upload. Used inside the "I need help" modal of the Add project wizard. {% endcomment %}

{% trans "These are the steps you need to follow after adding the project:" %}

  1. {% url "profiles_tokens" as tokens_url %} {% blocktrans trimmed %} Create an API token and store it as a secret named READTHEDOCS_TOKEN in your pipeline. {% endblocktrans %}
  2. {% trans "Add the upload step after the step that builds your documentation, using the upload action or the command line client." %}
  3. {% trans "Push to your repository. The uploaded documentation shows up as a version of your project." %}

{% trans "GitHub Actions" %}

.github/workflows/docs.yaml 
# Build your documentation with the tool you already use, then upload it
- uses: readthedocs/upload-action@v1
  with:
    token: ${% templatetag openvariable %} secrets.READTHEDOCS_TOKEN {% templatetag closevariable %}
    project-slug: {{ project_slug|default:"<your-project-slug>" }}
    html: _build/html

{% trans "Command line" %}

console 
$ export READTHEDOCS_TOKEN=<token>
$ uvx --from readthedocs-upload readthedocs upload \
    --project-slug {{ project_slug|default:"<your-project-slug>" }} \
    --html _build/html

{% blocktrans trimmed with url="https://docs.readthedocs.com/platform/stable/guides/build/direct-upload.html" %} Pushes to a branch or tag create that version on Read the Docs, and pull requests get previews. Read more in the direct upload documentation. {% endblocktrans %}
